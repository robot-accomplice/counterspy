# ABORT Review — Publish the CounterSpy TUI (v0.2.0-rc2)

**Reversibility & blast radius:** The release is revertible (a tag). New TUI-specific
surface: a raw-mode terminal + event loop running under **root**. Blast radius beyond the
CLI's = terminal corruption on an uncaught exit, an interactive quarantine path, and a new
untrusted input (`--from` snapshots). Quarantine itself remains reversible (move-not-delete
+ restore). The CLI core (`act`/`score`/`interpret`) was ABORT-reviewed at v0.1.0; this gate
scopes the **TUI increment**.

**Decision under review:** Publish `counterspy tui` (v0.2.0-rc2, tcell) — an interactive UI
that, under sudo, quarantines user-selected items on Macs; `--from` snapshots are read-only.

**Mechanical gates:** `go test ./...` green (74 tests), `vet`/`gofmt` clean, `architext`
valid, `-race` clean, renders on a real terminal.

---

## A — Premortem

> We shipped the TUI, and it failed because a user on an unusual terminal — or after a
> panic/external kill mid-loop — had their terminal **left in raw mode**; and/or the snappy
> UI made it **frictionless to sweep-quarantine** legit software before realizing.

**The one sentence that stops the ship:** *"We never tested the TUI on a terminal that
isn't the developer's, nor what happens when it's killed mid-loop."*

---

## B — Station verdicts (verbatim, unaveraged)

1. **Attacker — GO-WITH-CONDITIONS.** DoS: `loadSnapshot` unbounded + `truncate` materializes
   the full string every redraw → a 100 MB verdict in a hostile snapshot freezes/OOMs the
   "safe to open" read-only workflow. Read-only rests on a single UI `if` with no actor-layer
   defense-in-depth. Unicode/RTLO spoofing slips past `Clean`. (Confirmed: no modal
   bait-and-switch — `a.Actions` shown == moved.)
2. **Worst-Case Customer — NO-GO.** No OS signal handlers → an external `SIGTERM`/`SIGHUP`
   (kill, SSH drop) bypasses the deferred `Fini` and leaves the terminal raw; a novice
   can't recover. Also: no width guard; coarse session-undo.
3. **Resource Auditor — GO-WITH-CONDITIONS.** TUI justifies its cost (filtering kills prompt
   fatigue), `-race` clean, no flakes. But `visible()` recomputed 2–3×/keystroke (perf cliff
   claim), and the tcell tree (8 modules) is **not vendored** in a root binary.
4. **Future-Me — GO-WITH-CONDITIONS.** `recover()` logs only the panic value (no stack) →
   a field crash is un-RCA-able. The architext `mod-tui` node claims a `mod-act` dependency
   the code doesn't have. The decoupling invariant is convention-only (no CI). "vendored"
   claim is false. (Confirmed: pure/impure split real; manifest RCA trail shared CLI↔TUI.)
5. **Domain/Integrity — GO-WITH-CONDITIONS.** A partial restore clears `Done` only on full
   success → items moved back still show "✓ quarantined" (misreports containment). Read-only
   is a single `if` (= Attacker #2). A failure toast overclaims "recorded" when nothing was.
   (Confirmed strongest: the actor **re-runs every guard at move-time** regardless of the TUI,
   and the modal is single-sourced — the TUI genuinely inherits the hardened mutation path.)

**Tally: 1 NO-GO, 4 GO-WITH-CONDITIONS.**

### Root-cause clusters

- **C1 — The TUI shell doesn't survive abnormal exit** (#1, #5, #13): no signal handling, no
  stack on panic. Leverage: signal→Fini + `debug.Stack`.
- **C2 — Untrusted `--from` input isn't bounded or defended in depth** (#2, #3, #6): size cap,
  actor-layer read-only refusal, Unicode-strip.
- **C3 — Dashboard can misreport on-disk state** (#4): clear `Done` on any restore result.
- **C4 — Docs/invariant drifted ahead of code** (#7, #8): vendor, fix architext, CI import-guard.
- **C5 — Small-terminal / perf polish** (#9, #10): width guard, one `visible()` call, benchmark.

### The one fix (highest-risk cluster, C2)

**Bound and defend the `--from` boundary**: a 16 MiB snapshot cap, a `truncate` byte-guard,
an actor-layer read-only refusal, and Unicode-spoof stripping — neutralizing #2, #3, #6 at
once so a snapshot someone hands you can neither DoS you nor be tricked into a root file move.

### Acceptable risks (monitor/document)

- **#9 perf** — measured at 19µs/500 findings; the "100ms lag" was overstated ~5000×.
- **#11 coarse undo** — session-scoped restore is a documented design choice (`u` undoes the
  session; the CLI can restore a specific manifest). Deferred: per-item undo (needs the
  Actor to return per-item outcomes).
- **#12 snapshots lack gaps** — deferred (T-8): changing the `--json` contract to embed gaps
  is out of scope for this fix; a snapshot is a point-in-time export, run live for gap info.
- **#13 tcell goroutine panic** — inherent to any tcell app; the signal handler covers
  external kills, and `SIGKILL` is uncatchable for every TUI.

### Dealbreaker

**YES, two for immediate rc2 publish:** the terminal-corruption-on-kill (C1) and the
untrusted-snapshot DoS + one-`if` read-only (C2). Both are code-verified and both fixable.

## T — Go / No-Go

- **Confidence: 8/10** in **NO-GO for immediate v0.2.0-rc2 publish** — real, verified blockers.
- **Blocking issue:** a root TUI that can be left corrupting a stranger's terminal on kill, and
  DoS'd / one-refactor-away from moving files from untrusted JSON.
- **Station verdicts:** Attacker GW-C · Customer NO-GO · Auditor GW-C · Future-Me GW-C · Domain GW-C.

### FINAL VERDICT

- **Immediate v0.2.0-rc2 publish: NO-GO.**
- **Personal / beta use: GO** — the core mutation path is confirmed hardened and inherited;
  the blockers are shell-level and about the *public/adversarial* context.

### Convertibility conditions → GO

C1 terminal survival (signal handler + `debug.Stack`) · C2 bound+defend `--from` (cap, byte-guard,
actor read-only, Unicode-strip) · C3 clear `Done` on any restore · C4 vendor + fix architext + CI
import-guard · C5 width guard + single `visible()` + benchmark.

**Project-lead summary:** The TUI genuinely inherits the CLI's hardened, guard-re-running
mutation path and its manifest RCA trail — the concern was never the core, it was the shell:
does it survive a kill, and can untrusted JSON hurt you. Meet the five conditions and it's a GO.

## Closure — v0.2.0-rc3 (all conditions met, verified)

Every convertibility condition addressed against source + tests (76 tests + benchmark green,
`-race` clean, `architext` valid):

- **C1 — DONE.** `runTUI` installs a `SIGINT`/`SIGTERM`/`SIGHUP` handler → `screen.Fini()` +
  exit, restoring the terminal on external kill (`SIGKILL` is uncatchable — true of any TUI).
  `recover()` now writes `debug.Stack()` to **stderr**.
- **C2 — DONE.** `loadSnapshot` caps at 16 MiB; `truncate` byte-guards before `[]rune`;
  `cliActor.readOnly` refuses quarantine at the **actor** boundary (`TestCliActor_ReadOnlyRefuses`);
  `model.Clean` now strips bidi overrides/isolates + zero-width (RTLO spoof closed).
- **C3 — DONE.** `Run` clears `Done` on **any** restore result and tells the operator to
  rescan; the "recorded" toast is now accurate (only when a manifest was actually written).
- **C4 — DONE.** tcell **vendored** (`vendor/`, the claim is now true); `architext` `mod-tui`
  corrected to depend only on `mod-model` (the act seam is `main`'s `cliActor`); a new
  `TestDecouplingInvariant` parses `internal/tui`'s imports and fails CI if anything but
  `internal/model` is imported — the invariant is enforced, not remembered.
- **C5 — DONE.** width guard + modal-height clamp; `visible()` computed once per event;
  `BenchmarkVisible` records the real cost (19µs/500 findings), grounding the perf note.
- **Deferred with justification:** per-item undo (needs Actor per-item outcomes; T-9),
  gaps-in-snapshots (JSON-contract stability; T-8).

**REVISED VERDICT:** GO for personal/beta (strengthened). General-public GO remains gated on
the CLI's inherited condition (field false-positive measurement) — the TUI adds no new public
blocker now that C1–C5 are closed. A further re-ABORT after any additional public-hardening
remains advisable.
